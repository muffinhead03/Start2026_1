## 1. 문제
1) 퍼즐 힌트 문제
- 기존 방탈출·퍼즐 게임은 특정 구간의 난이도가 높아지면 유저가 더 이상 진행하지 못하고 포기하는 경우가 있다.  
- 난이도가 너무 높거나 낮으면 자칫 유저가 스토리와 분위기에 몰입하기보다 답답함을 느끼게 된다.
- 힌트가 유저 맞춤형이 아닌 경우가 많다. 
2) API 비용부담
- 기존 게임들은 종종 Ai API를 사용하는데, 이는 사용자가 결국 비용을 부담하게 된다.

따라서 **퍼즐의 재미는 유지하면서도, 유저가 막혔을 때 자연스럽게 도움을 받을 수 있는 방식**이 필요하다고 보았다.

## 2. 해결 아이디어
저희는 이 문제를 해결하기 위해 **LLM 기반 맞춤형 힌트 시스템**을 제안한다.
1) 퍼즐 힌트 문제
- 유저가 단서를 찾지 못하거나 특정 퍼즐에서 오래 헤매는 경우, 게임 내에서 LLM에게 도움을 요청할 수 있다.  
- 이때 LLM은 단순히 미리 정해진 힌트를 보여주는 것이 아니라, 유저의 현재 진행 상황, 수집한 단서, 플레이어의 질문을 바탕으로 상황에 맞는 힌트를 제공한다.
- 힌트는 정답을 바로 알려주는 방식이 아니라 단계적으로 제공된다.  
2) API 비용부담
  소형 llm을 탑재해서, 사용자가 API 사용 비용에 대해 부담하지 않도록 한다. 
이를 통해 유저는 스스로 퍼즐을 해결하는 재미와 성취감을 유지하면서도, 지나치게 어려운 구간에서 게임을 포기하지 않고 계속 몰입할 수 있다.

### 3. 기술/구현

**사용 기술:** Unity (게임 엔진) + Ollama (로컬 LLM)

**실행 환경:**
- 게임 실행 시 Ollama가 로컬 HTTP 서버로 자동 실행 (localhost)
- 인터넷 연결 없이 유저 PC에서 직접 동작하는 온디바이스 구조

**동작 흐름:**
1. 유저가 게임 내에서 힌트 요청
2. Unity가 HTTP 요청으로 로컬 Ollama 서버에 전달 (플레이어 진행 상황 + 수집 단서 + 질문)
3. Ollama가 상황에 맞는 힌트 생성 후 반환
4. Unity가 결과를 받아 게임 화면에 출력

**핵심 특징:**
- 외부 서버 불필요 → 빠른 응답 속도, API 비용 없음

### 4. MVP/배포
- MVP: 단서를 수집해 밀실을 탈출하는 공포 방탈출 게임
- 배포
    - 기말: 팀원들 각자 1개의 맵을 제작해, 총 3개 스테이지로 구성된 데모 빌드 파일
    - 9월: 방학 때 볼륨을 두 배로 키워, 총 6개 스테이지의 빌드 파일 스팀에 출시.

### 5. 차별성
기존 레퍼런스 게임의 단점: 특정 단계에서 막히면 몰입이 깨진다. <br/>
**-> 유저가 원할 때 LLM이 현재 진행 상황을 분석해 맞춤형 힌트를 제공, 유저의 몰입감을 유지.**

### 6. PMF
**BACKROOMS: ESCAPE TOGETHER**
여러 명의 플레이어가 함께 협력하여 탈출하는 멀티플레이 공포 방탈출 게임.
각 맵에는 다양한 퍼즐과 이상현상이 존재하며, 플레이어들은 서로 정보를 공유하고 협력하여 문제를 해결해야 한다.
넓고 반복되는 구조의 공간과 갑작스럽게 등장하는 위협 요소를 통해 긴장감을 극대화하며, 혼자가 아닌 협동 플레이를 통해 공포를 완화하면서도 전략적인 플레이를 요구한다.
퍼즐과 생존 요소가 결합되어 있으며, 커뮤니케이션과 역할 분담이 중요한 게임이다.

**PoppyPlaytime**
폐쇄된 장난감 공장을 배경으로 한 1인칭 공포 퍼즐 게임.
플레이어는 ‘그랩팩(GrabPack)’이라는 도구를 활용해 전기를 연결하거나, 물체를 조작하고, 퍼즐을 해결하며 공간을 탈출해야 한다.
퍼즐은 단순한 문제 풀이가 아니라 환경과 도구를 활용하는 상호작용 중심 구조이며,
게임 진행 중 적(허기 와기 등)에게 쫓기는 구간이 등장해 퍼즐과 생존 요소가 결합되어 있다.
또한 색상, 전선 연결, 동선 파악 등 직관적인 규칙을 기반으로 설계되어
플레이어가 스스로 규칙을 이해하고 해결하도록 유도하는 구조를 가진다.

**8번출구**
반복되는 지하 통로를 탈출하는 1인칭 이상현상 탐지 게임.
플레이어는 같은 구조의 공간을 계속 이동하며, 주변 환경에서 발생하는 미세한 변화(이상현상)를 관찰해야 한다.
이상현상이 없으면 앞으로, 있으면 뒤로 돌아가는 방식으로 진행되며,
관찰과 판단이 핵심 플레이 요소이다.
게임은 별도의 설명 없이도 플레이어가 규칙을 스스로 학습하도록 설계되어 있으며,
작은 변화 하나에도 긴장감을 느끼게 만드는 심리적 공포를 강조한다.
