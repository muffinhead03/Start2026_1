# 실험 결과 — wine_glass_room

실험 일시: 2026.04 ~ 2026.05  
모델: gemma3:1b → gemma3:4b  
씬: `wine_glass_room` (와인잔 얼룩 교차점 퍼즐)

---

## Case 1 — 한국어 응답 뒤 영어 번역 자동 삽입 (gemma3:4b, 초기)

**입력 상황**
- hintLevel: 2
- playerStatus: 단서 미발견
- 질문 유형: puzzle

**실제 응답**
```
와인잔의 색깔을 자세히 살펴보세요. (Look closely at the colors of the wine glasses.)
```

**문제점**  
한국어 응답 뒤에 영어 번역이 괄호 형태로 자동 삽입됨. 게임 UI에 그대로 출력되어 공포 분위기를 해침.

**해결**  
`OllamaClient.ParseResponse()`에서 `(` 위치를 탐지해 괄호 이전까지만 잘라내는 로직 추가.

```csharp
int bracketStart = result.IndexOf('(');
if (bracketStart > 0) result = result.Substring(0, bracketStart).Trim();
```

## Case 2 — 시스템 프롬프트 한국어 작성 시 응답 품질 저하

**실험 내용**  
시스템 프롬프트를 한국어로 작성했을 때와 영어로 작성했을 때 응답 품질 비교.

**한국어 프롬프트 (초기 시도)**
```
당신은 한국어 공포 방탈출 게임의 힌트 안내 AI입니다.
반드시 한국어로만 답변하세요.
1~2문장으로만 답변하세요.
```

**한국어 프롬프트 응답 결과**
```
네, 알겠습니다. 와인잔을 살펴보시면 단서를 찾을 수 있을 것입니다. 
색깔별로 구분해서 확인해보시는 것이 좋을 것 같습니다. 
또한 얼룩의 패턴도 주의 깊게 관찰해보세요.
```

**문제점**
- "네, 알겠습니다" 같은 불필요한 도입부 생성
- 문장 수 제한(1~2문장) 미준수 — 3문장 이상 출력
- 공포 분위기 없이 안내원 말투로 출력
- 씬 컨텍스트를 반영하지 않은 일반적 힌트

**영어 프롬프트 응답 결과**
```
얼룩이 남긴 흔적을 따라가보세요... 같은 색은 같은 곳을 가리키고 있습니다.
```

**결론**  
gemma3:4b는 영어 시스템 프롬프트에서 지시 준수율이 훨씬 높음. 한국어 프롬프트는 문장 수 제한, 말투 제어 모두 불안정. 최종 시스템 프롬프트를 영어로 확정.

## Case 3 — hintLevel 미반영 (gemma3:1b)

**입력 상황**
- hintLevel: 1 (가장 간접적)
- hintLevel: 5 (가장 직접적)
- 두 케이스에 동일 씬 컨텍스트 적용

**hintLevel 1 응답 (gemma3:1b)**
```
와인잔과 얼룩을 잘 살펴보세요.
```

**hintLevel 5 응답 (gemma3:1b)**
```
와인잔과 얼룩을 잘 살펴보세요.
```

**문제점**  
레벨 1과 5에서 거의 동일한 응답 생성. 힌트 강도 차별화 불가.

**hintLevel 5 응답 (gemma3:4b)**
```
같은 색 얼룩 두 개를 이어보면 바닥에 숫자가 보입니다. 그 숫자만큼 와인 이름의 첫 글자를 밀어보세요.
```

**결론**  
gemma3:4b가 hintLevel에 따른 힌트 강도 차별화를 실제로 수행함. gemma3:4b 최종 채택 결정.
