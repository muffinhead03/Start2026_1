# 모델 비교 실험 — gemma3:1b vs gemma3:4b

실험 일시: 2026.04  
환경: Ollama 로컬 (Mac, localhost:11434)  
목적: 두 모델 중 게임 힌트 시스템에 적합한 모델 선정

---

## 평가 기준

| 항목 | 설명 |
|------|------|
| 한국어 유지 | 응답 전체가 한국어로만 구성되는지 |
| 문장 수 제한 | 1~2문장 이내로 응답하는지 |
| hintLevel 반영 | 레벨에 따라 힌트 강도가 달라지는지 |
| 씬 컨텍스트 활용 | 씬 오브젝트·구조를 반영한 힌트를 생성하는지 |
| 분위기 유지 | 공포스럽고 불길한 말투를 유지하는지 |
| 안정성 | 코드블록·영어 괄호 등 이물질 삽입 빈도 |

## 비교 결과

| 항목 | gemma3:1b | gemma3:4b |
|------|-----------|-----------|
| 한국어 유지 | ❌ 간헐적으로 영어 단어 혼입 | ⚠️ 한국어 유지되나 영어 괄호 번역 자동 삽입 (후처리로 해결) |
| 문장 수 제한 | ❌ 3~5문장 초과 빈번 | ✅ 1~2문장 대체로 준수 |

| 씬 컨텍스트 활용 | ❌ 일반적 힌트에 그침 | ✅ 씬 오브젝트 기반 힌트 생성 |
| 분위기 유지 | ❌ 안내원 말투 빈번 | ✅ 불길한 분위기 유지 |
| 안정성 | ❌ 코드블록·영어 혼입 빈번 | ⚠️ 간헐적 발생 (후처리로 해결) |

## 샘플 응답 비교

**입력 조건**
- 씬: `organ_room`
- hintLevel: 3
- 질문 유형: puzzle
- 현재 단계: 파이프 수집

**gemma3:1b 응답**
```
Look around the room carefully. There might be pipes hidden somewhere. 
Check every corner of the mansion to find what you need.
파이프를 찾아보세요.
```
→ 한국어·영어 혼재, 3문장 초과, 씬 구조 미반영

**gemma3:4b 응답**
```
이 저택 어딘가에 숨겨진 것들이 당신을 기다리고 있습니다... 오르간이 다시 숨을 쉬려면 네 개가 필요합니다. (Four things are needed for the organ to breathe again.)
```
→ 씬 컨텍스트 반영, 분위기 유지, 영어 괄호는 후처리로 제거

---

## 후처리 필요 항목 (gemma3:4b 채택 후)

| 현상 | 빈도 | 해결 방법 |
|------|------|----------|
| 영어 괄호 번역 자동 삽입 | 높음 | `(` 위치 탐지 후 이전까지 자르기 |
| 마크다운 코드블록 삽입 | 낮음 | 백틱 패턴 제거 |
| 응답 앞뒤 따옴표 | 간헐적 | `Trim('"')` 처리 |

## 최종 결정

**gemma3:4b 채택**

gemma3:1b는 문장 수 제한·hintLevel 반영·한국어 유지 모두 불안정하여 게임 힌트 시스템에 부적합 판정.  
gemma3:4b는 후처리 로직으로 보완 가능한 수준의 이슈만 존재하며 전반적인 품질이 게임 요구사항을 충족.  
`OllamaClient.cs`에 모델명 `"gemma3:4b"` 고정 및 후처리 로직 구현 완료.
